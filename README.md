# Civil Element Calculator

A Python command-line program that calculates the volume and weight of
reinforced concrete beams, columns, and slabs.

## Features

- Menu-driven program (add beam, column, or slab)
- Input validation (rejects text, zero, and negative values)
- Object-oriented design using inheritance (`Element`, `Beam`, `Column`, `Slab`)
- Saves data to a file and loads it again on the next run
- Summary of total volume and total weight

## How to run

1. Install Python 3.
2. Download or clone this repository.
3. Run:

```
python main.py
```

## Example

```
1. Add beam
2. Add column
3. Add slab
4. Show summary
5. Save and exit
```
